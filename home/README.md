| [`dankmaterialshell/`](./dankmaterialshell/) | DankMaterialShell bar, launcher and widgets (`settings.json` is symlinked, so it stays editable) |

| [`niri/`](./niri/) | Niri config |
| [`programs/`](./programs/) | User packages: applications, CLI tools and services |

| [`wallpapers/`](./wallpapers/) | Wallpapers |
